# Branding assets

This directory intentionally contains no Government of Canada marks.

Users who are authorized to use an approved bilingual NRCan corporate
signature or Canada wordmark should keep those files in their own project and
reference them with the `cfs-corporate-signature` and `cfs-canada-wordmark`
metadata fields. Never substitute, trace, recolour, crop, or redistribute an
official mark as part of this extension.
